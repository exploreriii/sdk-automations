# 9.5 Fork pull request

Written 2026-10-17. Not yet run.

**Question this can falsify:** that a fork's pull request under `pull_request_target` posts the
dashboard comment with the base's token, runs no code from the head, and does not execute a `run:`
step added to the fork's copy of the workflow.

## Setup

- The common sandbox: a personal repository whose workflow checks out `hiero-hackers/sdk-automations` at the
  commit under test, builds the bundle (`pnpm install --frozen-lockfile && pnpm --filter
  @hiero-hackers/automation-runtime build:action`) and runs `uses: ./`. The run summary and the Actions
  log are the evidence. Where the real event is hard to provoke, a `workflow_dispatch` writes the
  captured payload to `GITHUB_EVENT_PATH` and runs the same step. Record the commit at step 1.
- A second account owns the fork. Config `mode: active`, `prDashboard` enabled, `arm-writes: "true"`.
  The workflow has no checkout of the head, ever.
- On the fork's branch: a `run: echo FORK-STEP-RAN` step added to the workflow file, and a file the
  engine would read if it executed head code (a changed `sdk-automations.yml`).

## Steps

1. Record the commit. From the fork, open a pull request against the sandbox.
2. Read the run: it is the base repository's workflow, triggered by `pull_request_target`. Record
   the token's permissions line in the log.
3. Expect the dashboard comment on the pull request, authored by `github-actions[bot]`; record the
   author and the time.
4. Search the log for `FORK-STEP-RAN`. Expect no match, and no step the base workflow does not
   contain.
5. Push a second commit to the fork changing the config. Expect the run to read the base's
   configuration, not the head's.
6. Confirm the fork's own Actions run, if any, has no secrets and no write token to the base.
7. Close the pull request; delete the fork's branch.

## Expected result

The summary shows the decision and the comment landed with the base's token; the fork's step is
absent from the log; the head's configuration changes nothing.
